# C 盘空间增长监控器

这是一个面向 Windows 的磁盘空间监控工具。每次启动都会创建一个监控会话，通过启动和关闭两次目录快照，记录本次总增长量并找出增长最多的目录和文件。

> 当前交付候选：v0.6.3（已完成自动化与 EXE 验证，待用户验收）。

## 当前功能

- 定时记录磁盘总量、已用量和剩余量
- 每次启动建立容量和目录基线，正常关闭时自动保存结束快照
- 下次启动展示上一次会话的总增长量和具体增长路径
- 后台扫描任意目录，不阻塞界面
- 矩形面积图展示当前目录的空间分布
- 对比同一路径最近两次扫描，显示增长来源
- 显示最近 24 小时、7 天或 30 天的磁盘占用趋势
- 跳过目录联接、符号链接和无权限目录，避免循环或崩溃
- 扫描过程中可取消
- 自动清理 30 天以前的分钟采样，避免数据库持续膨胀
- 原始目录快照保留 90 天，会话汇总长期保留
- 增长与减少视图切换，可确认新增占用或清理效果
- 双击变化目录可直接继续扫描，深层变化会给出钻取提示
- 一次扫描构建会话级目录骨架；深层目录优先从内存秒开，不再重复扫描
- 每目录显示有限大文件，其余小文件聚合为“其他文件”；骨架超过 50 MB 预算时自动精简文件明细
- “↑ 上一级”和可点击面包屑支持目录往返；骨架未命中时再使用本次缓存、历史快照或重新扫描
- “重新扫描当前目录”会让当前层及其下级缓存失效，避免误用刷新前数据
- 增长来源使用可展开的层级树，父目录只做汇总，变化量只在叶子明细显示
- 无法归属到已记录子项的差额显示为“其他未展开变化”，去重时不丢失数值
- 可保存带备注的手动快照，并在快照历史页选择任意两个同路径标记点对比
- 主区域分为“空间分布、空间变化、快照历史”三个标签页，查看与操作职责更清晰
- 正常完整关闭后，下次启动自动以上次关闭快照为连续基线；快速或异常退出则建立新基线
- 空间变化页可在“本次启动快照”和“最近完整保存”间手动切换，不修改或复制原快照
- 空间变化页分开显示文件快照变化、运行期间磁盘变化和未监控期间磁盘变化，三种口径禁止相加
- 单独提示未监控期间超过 100 MB 的磁盘变化，并与文件快照口径严格分开
- 快照历史显示时间、路径、大小、来源和备注，支持稳定分页及任意两个同路径快照对比
- 趋势图显示会话开始/结束、超过 5 分钟的未监控断层，并支持悬停查看精确采样
- Treemap 导航与扫描完成时使用轻量过渡动画，大型目录自动直接绘制
- Treemap 和增长树支持悬停查看完整路径、大小及文件数
- 可用空间同时显示容量和百分比；全局状态行汇总基线、扫描、骨架内存和盲区状态
- 单实例运行，防止重复会话互相污染
- 可在设置中启用 Windows 登录后自动启动
- 界面回调异常会写入轮转日志；绘图失败也会恢复扫描按钮并保留已经落库的快照
- 完整关闭成功后，日志会记录 closing 扫描收尾结果和结束快照编号，便于判断关闭全链路是否完成

## 直接运行

本机需要 Python 3.10 或更高版本。

```powershell
python run.py
```

程序数据保存在：

```text
%LOCALAPPDATA%\DiskGrowthMonitor\monitor.db
```

界面故障日志保存在：

```text
%LOCALAPPDATA%\DiskGrowthMonitor\ui.log
```

## 使用方法

1. 启动程序后会立即记录 C 盘用量，并自动建立本次会话的目录基线。
2. 运行期间“本次启动后变化”显示相对启动时的累计变化。
3. 正常关闭窗口时，可以选择“完整保存”“快速退出”或取消关闭。
4. 勾选“下次不再询问”会记住当前关闭方式；可在“设置”中随时改回“每次询问”。
5. 同路径完整关闭后，下次启动会自动以上次关闭快照为基线；快速或异常退出后会建立新基线。
6. 使用“增长 / 减少”切换查看占用增加或空间释放来源。
7. 双击矩形图或变化列表中的目录，可以进入该目录；一次完整扫描后，骨架命中的深层目录和“↑ 上一级”都不会重新扫描。
8. 需要获取最新数据时，点击“重新扫描当前目录”；程序会替换该目录及后代骨架，并同步更新所有祖先目录的大小。
9. 点击“保存快照”并填写备注，可以标记清理前后等关键时刻。
10. 在“快照历史”中普通单击任意两条同路径记录，再点击“对比所选两项”；程序会自动确定新旧并显示相隔时间。
11. 在“空间变化”中可手动切换“本次启动快照 / 最近完整保存”；“恢复默认基线”只恢复启动时自动判定结果，不会删除任何快照。
12. 点击“取消扫描”可以安全停止手动扫描。取消启动基线后，本次会话只能保存总增长量，无法生成完整地址差异。
13. 在趋势图右上角切换“24 小时 / 7 天 / 30 天”；橙色区域表示超过 5 分钟没有采样，灰色竖线表示会话边界。

## 打包

```powershell
python -m pip install pyinstaller
./build.ps1
```

生成的程序位于 `dist/C盘空间增长监控器.exe`。

## 已知边界

- 当前统计的是文件逻辑大小，与 NTFS 实际分配空间可能存在小幅差异。
- 硬链接可能被重复计数。
- 未以管理员身份运行时，部分系统目录无法读取；程序会跳过并统计错误数。
- 地址差异数据库仍默认覆盖两层目录和全盘最大的 200 个文件。会话内导航骨架可以秒开深层目录，但深层小文件的历史变化仍需进入相关目录后重新扫描才能建立更细快照。
- 导航骨架只在当前程序会话中保留，重启后会按历史快照或重新扫描流程恢复。
- 正常关闭会等待结束扫描完成。系统强制关机时受 Windows 退出时限影响，程序会优先保存总增长量，并尽量使用最近一次已完成的地址快照。
- 顶部累计变化使用磁盘已用容量口径；目录和文件明细使用文件逻辑大小口径，两者可能不完全一致。
- “50 MB 骨架预算”是每次扫描保留文件明细的软预算；目录节点是秒开导航所必需，不会为了达标而删除。底部状态会另行显示包含目录节点的骨架估算值，因此大规模目录树可能超过 50 MB。
- 文件快照、运行期间磁盘变化、未监控期间磁盘变化的起止时间和统计口径不同，只用于相互参照，不能直接相加或要求数值完全相等。
- 程序只分析和记录，不会自动删除任何文件。
